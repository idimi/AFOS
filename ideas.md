**Design Movement:** Terminal Brutalism meets Crypto-Native Dark UI
**Core Principles:** Raw data density, monospace honesty, neon-on-void contrast, zero decoration
**Color Philosophy:** Deep void black (#0a0a0f) with electric green (#00ff88) as the primary signal color — evoking terminal screens and crypto trading platforms. Amber (#f59e0b) for warnings, red (#ef4444) for destructive actions. No gradients, no softness.
**Layout Paradigm:** Asymmetric split — a narrow left rail (status + nav) and a wide main canvas divided into resizable panels. Data bleeds to the edges. No centered cards.
**Signature Elements:** Monospace font for all data values; blinking cursor animations; thin 1px borders that glow on hover
**Interaction Philosophy:** Every action feels like a terminal command — instant, precise, no hand-holding
**Animation:** Fade-in lines like a terminal printing; number counters that tick up; status indicators that pulse
**Typography System:** JetBrains Mono for data/values, Space Grotesk for headings, no serif anywhere

**Design Movement:** Bauhaus Functionalism + Swiss Grid
**Core Principles:** Form follows function, strict grid, typographic hierarchy, no ornament
**Color Philosophy:** Off-white (#f8f7f4) background with deep charcoal (#1a1a1a) text. Single accent: electric indigo (#4f46e5). Color is used only to communicate state, never decoration.
**Layout Paradigm:** 12-column strict grid. Sidebar is a narrow column. Content panels snap to grid. No rounded corners — sharp, architectural edges.
**Signature Elements:** Large bold section numbers; thick horizontal rules as dividers; tabular data in clean grids
**Interaction Philosophy:** Hover states are subtle underlines and color shifts — no bouncing, no scaling
**Animation:** Slide-in from left on page load; no spring physics, linear easing only
**Typography System:** DM Sans Bold for headings, DM Mono for data, strict size scale (12/14/16/20/28/40px)

## Chosen Approach: Glassmorphism + Agentic Sci-Fi

Deep navy-black base with layered glass panels, cyan-teal primary accent, violet secondary, gold for financial values. Left sidebar + live agent feed. Frosted glass cards with border glow. Outfit + JetBrains Mono typography.
